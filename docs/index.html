Install Tempus

It takes about a minute. You don't need an account. If macOS blocks Tempus, see Opening Tempus the first time.

  1. Open the download

    Double-click Tempus.dmg in your Downloads folder. A window opens with Tempus and your Applications folder.

  2. Drag to Applications

    Drag the Tempus icon onto the Applications folder, then eject the disk image from the Finder sidebar.

  3. Open Tempus

    Find Tempus in Launchpad or your Applications folder and open it. Press ⌘N to start your first timelapse.

Opening Tempus the first time

This build isn't notarized by Apple yet, so macOS blocks it until you approve it. You do this once for the disk image and once for the app. After that, Tempus opens normally.

Why the warning? Notarization is Apple's automated malware check for apps distributed outside the App Store. Tempus hasn't gone through it yet, so macOS can't confirm who made it. Only approve apps you downloaded from a source you trust, such as this page or the GitHub releases.

  1. Open the disk image

    Double-click Tempus.dmg. macOS shows a message like: "Tempus.dmg" Not Opened. Apple could not verify "Tempus.dmg" is free of malware…

    Click Done. Don't click Move to Trash.

  2. Allow it in System Settings

    Open Apple menu → System Settings → Privacy & Security. Scroll down to Security, where it says Tempus.dmg was blocked. Click Open Anyway.

  3. Confirm

    Enter your Mac password or use Touch ID, then click Open Anyway again in the dialog that appears. The disk image opens.

  4. Install the app

    Drag Tempus onto the Applications folder, then eject the disk image from the Finder sidebar.

  5. Open Tempus and allow it

    Open Tempus from Applications. macOS blocks it the same way. Click Done, go back to Privacy & Security, click Open Anyway next to Tempus, and confirm with your password.

  6. You're set

    Tempus opens. From now on it opens like any other app, including after you install updates the same way.

I don't see an Open Anyway button

The button only appears after you try to open the file, and only for about an hour afterward. Double-click Tempus.dmg or Tempus again, click Done, then go straight back to System Settings → Privacy & Security and scroll to the bottom of the page.

Right-clicking the app and choosing Open no longer skips this check on current versions of macOS. Use Privacy & Security instead.

Use Terminal instead (advanced)

macOS marks downloaded files as quarantined, and that mark is what triggers the block. After dragging Tempus to Applications, you can remove the mark in Terminal:

xattr -dr com.apple.quarantine /Applications/Tempus.app

Then open Tempus normally. This turns off the check only for Tempus. Only do this for apps from a source you trust.

Allow screen or camera access

macOS asks the first time you record. Tempus only uses access while a recording is running.

Screen Recording

When you record a display or window, macOS asks to allow screen recording. If you dismissed the prompt, open System Settings → Privacy & Security → Screen & System Audio Recording, turn on Tempus, and reopen the app.

Camera

When you pick a camera as the source, macOS asks for camera access. To change it later, go to System Settings → Privacy & Security → Camera.

What it does

Two ways to record, depending on how long you'll be working.

Screenshots mode

A full-resolution frame every 5 seconds to 2 minutes. Choose which frames to keep and export an MP4 at any speed.

Video mode

A sped-up HEVC video written live, 5× to 300×. One hour at 60× plays back in one minute.

Any source

Record a whole display, one window, or a connected camera.

Crash-safe

Pause and resume whenever you like. If your Mac restarts, your recording is still there.

Save where you want

Pick an exports folder once in Settings, or choose a location each time.

Private by design

No accounts, servers, analytics, or uploads. Tempus makes no network requests.

Help

Answers to common questions.

macOS says it can't verify the developer

This build isn't notarized yet. Follow the steps in Opening Tempus the first time. You only need to approve it once.

Tempus doesn't see my screen after I allowed access

macOS applies Screen Recording changes when an app relaunches. Quit Tempus with ⌘Q and open it again.

Where are my recordings stored?

Inside the app's private folder on your Mac. To find them, open Tempus Settings and click Show Recordings in Finder.

Exported videos go wherever you save them, or to the exports folder you picked in Settings.

How do I update?

Download the latest version from this page and drag it to Applications, replacing the old copy. Your recordings and settings are kept.

How do I uninstall?

Drag Tempus from Applications to the Trash.

To also delete your recordings, remove ~/Library/Containers/app.tempus.timelapse. This permanently deletes every timelapse you haven't exported.
